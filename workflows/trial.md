# 准备、运行和撤销试用

输入：资产或 Profile、目标项目、Codex/DSH、真实任务及希望观察的结果。任务缺少关键边界时先澄清；范围足够时直接推进已授权操作。

1. 读取目标项目约定，找到相关上下文。依据 catalog 和 Profile 确定最小资产集，读选中的完整 Skill。标准等非 Skill 资产走各自采用指南。
2. 调用 prepare（无 --apply）预览依赖、临时名称和目标路径。用户已授权试用时继续加 --apply 执行，无需反复确认。
3. 工具复制完整资源，使用本次独立的 trial 名称，并记录所选标识符转换。二进制资源和外部 URL 保持原样；原版源码及个人用户级目录不变。不是所有宿主都能在正在运行的会话中刷新目录，按适配文档选择新会话或给出续接指令。
4. 读取生成的 PROMPT.md，用宿主支持的调用入口执行本次任务。验证实际加载文件与输出证据。若只是主 Agent 读源文件执行，应记录 manual-guided，不能声称 native invocation 已验证。
5. 将产物放在目标项目约定位置或明确的临时试用位置。trials 保存简短证据和引用，使用 record 写入本次确实使用/尝试的资产。依赖被安装不代表被执行。
6. 运行 cleanup。工具只删除摘要仍匹配的管理目录；修改、新增、缺失文件会受到保护。返回 cleanup-needs-review 时指出实际残留，不强删。
7. 输出效果、限制、清理状态及建议。是否纳入留给用户；不同模型、手动调用或命名转换产生的差异也记录。

常用命令见 [工具说明](../scripts/README.md)。运行状态在忽略提交的 `.local/trials/<run>/`；可共享证据在 `trials/<run>/`。
