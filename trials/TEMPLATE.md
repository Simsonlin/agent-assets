# 试用观察模板

- run ID：
- 资产 ID、固定版本：
- 宿主与实际版本：
- 任务、材料范围、希望验证的用途：
- 文件准备与完整性检查：
- 原生发现证据：verified / unverified；证据引用
- 原生调用证据：verified / unverified；实际入口与读取路径
- 观察结果：useful / limited / inconclusive / blocked
- 产物或可观察证据：
- 方法帮助与限制：
- 撤销结果及需保留的残留：
- 建议：继续原版试用 / 考虑特化 / 建议纳入 / 暂待环境恢复
- 用户决定：尚未决定，或引用实际决定记录

填写观察后用 record 命令登记。复制成功、依赖已安装或正文已手动阅读，不单独证明原生调用或方法有效。
